# 获取「客户端专用密码」

腾讯企业邮箱开启「安全登录」后，第三方客户端（包含本 skill 的 IMAP/SMTP 调用）**必须使用客户端专用密码**，而不是网页登录密码。

## 步骤

1. 浏览器登录企业邮箱网页版：`https://exmail.qq.com/`
2. 右上角 **设置** → **微信绑定**（或「账户安全」）
3. 启用 **安全登录**（若未启用）
4. 在「客户端专用密码」区域点击 **新建** / **生成**
5. 输入用途备注（如 `agent-skill`），系统生成 16 位字符密码
6. **立即复制保存**（关闭后无法再次查看，但可重新生成）

## 使用

将该密码通过 `--password` 参数传给 `scripts/exmail.py`。

## 撤销 / 重置

在同一页面可以删除某条客户端专用密码（如怀疑泄露），然后新建一个并更新到本地配置。

## 管理员未放开 IMAP/SMTP 怎么办？

需要联系企业管理员：
- **企业微信管理端 → 协作 → 邮件 → 安全管理 → 客户端访问权限**
- 开启 IMAP/SMTP 的服务范围（可指定到具体成员或部门）
